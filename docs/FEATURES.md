# Features

- Dashboard with occupancy, revenue, outstanding balances, and recent activity
- Rooms with dual rates (semester and recess) and per-term allocations
- Resident directory with search, check-in/check-out, balances, and next-of-kin records
- Payments ledger with receipt numbering and printable PDF receipts
- Team management with email-based login and backend-enforced sessions
- Database backup and restore
- Per-hostel preferences (receipt footer, currency)
- Offline license activation — no network required
